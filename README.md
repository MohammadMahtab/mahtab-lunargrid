## Highlights

| | |
|---|---|
| **Moon themes** | 4 animated themes with a circular reveal switch |
| **Player names** | Custom names, kept after a refresh in the same tab |
| **Sound** | Move, win and draw sounds with a mute toggle |
| **Win animation** | Strike line, shockwave and confetti |
| **Keyboard play** | Fully playable without a mouse |
